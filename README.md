# Netflix Content Performance & Release Strategy Analysis

Business Analytics project analyzing Netflix viewing data to identify audience engagement patterns and provide data-driven recommendations for content and release strategy.

## Tech Stack
- Python
- Pandas
- NumPy
- Plotly
- Jupyter Notebook

## Key Insights
- TV Shows outperformed Movies in audience engagement.
- Globally available titles generated higher viewing hours.
- English content led total viewership, while Korean content showed strong engagement.
- Fridays, December, and Q4 were the strongest release periods.
